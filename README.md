Leonida Trophy Atlas — an offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5: every official name, description and grade, a guide in our own words with cited sources for each, a six-stage roadmap to the Platinum, missable flags, and a checklist that saves progress in the browser with export/import, kind and grade filters, search, and a spoiler setting that hides story trophies until earned. Everything runs from local files with no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the app serves `app/` statically and works with no network.
